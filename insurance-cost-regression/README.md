# Medical Insurance Cost Prediction

A machine learning project that predicts individual medical insurance charges from demographic and health attributes using scikit-learn regression models.

## Overview

This project builds a regression pipeline that estimates a person's yearly medical insurance charges from their age, sex, BMI, number of children, smoking status, and region. Five regression algorithms are compared with cross-validation, the strongest performer is selected automatically, retrained on the full training set, evaluated on a held-out test set, and exported as a reusable model file.

## Dataset

The project uses the [Medical Cost Personal Datasets](https://www.kaggle.com/datasets/mirichoi0218/insurance) (`dataset/insurance.csv`), containing 1,338 records across 7 columns with no missing values:

| Column | Description |
|---|---|
| `age` | Age of the primary beneficiary |
| `sex` | Insurance contractor gender (female / male) |
| `bmi` | Body mass index |
| `children` | Number of dependents covered by insurance |
| `smoker` | Smoking status (yes / no) |
| `region` | Residential area in the US (northeast, northwest, southeast, southwest) |
| `charges` | Individual medical costs billed by insurance — **target variable** |

## Approach

1. **Preprocessing** — `sex` and `smoker` are label-encoded to 0/1; `children` and `region` are one-hot encoded; `age` and `bmi` are median-imputed and standardized, all inside a single `ColumnTransformer`.
2. **Train/test split** — an 80/20 split stratified on `region` keeps regional proportions balanced across both sets.
3. **Model selection** — five regressors are compared using 5-fold cross-validation, scored on R²:
   - Linear Regression
   - Decision Tree
   - Histogram Gradient Boosting
   - Support Vector Regression (RBF kernel)
   - Random Forest
4. **Training** — the best model is retrained on the log-transformed target (`log1p`) to reduce the effect of the right-skewed charge distribution; predictions are converted back with `expm1`.
5. **Evaluation** — the final pipeline is scored on the untouched test set using R², MAE, RMSE, and MAPE.
6. **Export** — the fitted pipeline is serialized with `joblib` for reuse without retraining.

## Results

**Cross-validation (5-fold, R²):**

| Model | R² |
|---|---|
| Linear Regression | 73.17% (± 4.67%) |
| Decision Tree | 67.26% (± 3.06%) |
| Histogram Gradient Boosting | 82.21% (± 4.12%) |
| SVR (RBF) | 50.25% (± 6.19%) |
| **Random Forest** | **82.83% (± 3.65%)** |

Random Forest was selected as the best-performing model.

**Held-out test set performance:**

| Metric | Value |
|---|---|
| R² | 88.27% |
| MAE | $2,018.56 |
| RMSE | $4,230.88 |
| MAPE | 18.16% |

## Getting Started

### Prerequisites

- Python 3
- Jupyter Notebook or JupyterLab

### Installation

```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
pip install pandas numpy matplotlib seaborn scikit-learn joblib
```

### Usage

1. Place `insurance.csv` inside a `dataset/` folder in the project root.
2. Open and run `insurance.ipynb` top to bottom.
3. The notebook trains, evaluates, and saves the model as `charge_model.pkl`.

### Making Predictions with the Saved Model

```python
import joblib
import pandas as pd
import numpy as np

model = joblib.load("charge_model.pkl")

patient = pd.DataFrame([{
    "age": 19,
    "sex": 0,        # 0 = female, 1 = male
    "bmi": 27.9,
    "children": 0,
    "smoker": 1,     # 0 = no, 1 = yes
    "region": "southwest",
}])

predicted_charge = np.expm1(model.predict(patient)[0])
print(f"Predicted Medical Charges: ${predicted_charge:,.2f}")
```
